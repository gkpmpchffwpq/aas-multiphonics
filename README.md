## Overview

Multiphonics CV-1 models acoustic instrument resonators driven by audio-rate modulation to produce complex multiphonic tones — sounds that exist between pitched notes — for experimental sound design.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **AAS Multiphonics** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Resonator Models** | String, bar, and plate physical models driven to multiphonic states |
| **Audio-Rate Mod** | Modulate resonator excitation at audio frequencies for complex timbres |
| **Topology Blend** | Blend between parallel and series resonator coupling |
| **CV Modulation** | Continuous voltage-style modulation for generative parameter control |
